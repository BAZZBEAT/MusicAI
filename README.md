# 📊 MusicAI: In-Browser AI Music Analyzer

**MusicAI** — это полностью автономное одностраничное веб-приложение (SPA) для глубокого анализа музыкальных треков прямо внутри браузера. Приложение работает на стороне клиента (Client-side AI), задействуя вычислительные мощности устройства пользователя, не использует серверные бэкенды и не отправляет аудиофайлы в сеть, что гарантирует 100% конфиденциальность.

---

## 🛠️ Ключевые технологии

*   **Web Audio API (`OfflineAudioContext`)** — встроенный аудио-движок браузера. Используется для мгновенного декодирования загружаемых файлов (`.mp3`, `.wav`) и их принудительного ресемплинга в моно-сигнал с частотой дискретизации **16 000 Гц**, под которую строго оптимизирована архитектура MERT.
*   **Transformers.js v3 & WebGPU** — библиотека от Hugging Face, которая запускает ИИ-модели прямо в JavaScript. Она компилирует тяжелые веса в формат WebAssembly и задействует видеокарту (GPU) пользователя через современный стандарт **WebGPU** для сверхбыстрого инференса.
*   **MERT-v1-95M (квантованная INT8 версия)** — базовая трансформерная модель для извлечения признаков (Feature Extraction). Она «прослушивает» сырую звуковую волну и превращает её в плотный математический вектор (эмбеддинг).
*   **Векторный поиск (Косинусное сходство)** — математический алгоритм (`cosineSimilarity`), который сравнивает полученный 768-мерный вектор вашей песни с векторами известных мировых хитов, вычисляя процент их акустического сходства на основе геометрии векторов.
